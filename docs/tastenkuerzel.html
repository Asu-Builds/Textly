Tastenkürzel

Alles geht auch mit der Maus. Wer gern die Tastatur benutzt, kommt mit diesen Kürzeln schneller voran.

Am häufigsten

Strg+ZRückgängig
Strg+YWiederholen
EntfAusgewähltes Element löschen
EscSchreiben beenden
Strg+VBild aus der Zwischenablage einfügen

Elemente

Strg+DAusgewähltes Element verdoppeln
← ↑ → ↓Ausgewähltes Element verschieben (mit Umschalt in grösseren Schritten)
Alt beim ZiehenNicht am Raster einrasten
Strg+RBild nach rechts drehen (mit Umschalt nach links)

Text

Strg+B / Strg+I / Strg+UFett / Kursiv / Unterstrichen
TabIn der Tabelle: nächste Zelle (mit Umschalt: vorherige)

Ansicht

Strg++ / Strg+−Vergrössern / Verkleinern
Strg + MausradVergrössern / Verkleinern
Strg+0Ganze Seite zeigen
Strg+OZu «Meine Dokumente»
Strg+SSpeichern bestätigen (Textly speichert ohnehin automatisch)

In Textly zeigt das ? oben rechts dieselbe Übersicht.
